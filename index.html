Robótica Educativa: Innovación y Futuro

Proyecto Escolar Interactivo — 2.º Año

¿De qué trata este proyecto?

La robótica educativa es mucho más que armar piezas: es una disciplina fundamental para estimular el pensamiento computacional, la lógica y la creatividad. A través de este espacio digital documentamos los conceptos clave aprendidos durante el ciclo lectivo.

Actividades y Prácticas Realizadas

  • Introducción al Hardware: Estudio y reconocimiento de componentes electrónicos básicos, placas y sistemas lógicos.
  • Lógica de Programación: Análisis de estructuras de control, diagramas de flujo y resolución de problemas algorítmicos.
  • Desarrollo Web Escolar: Creación, estructuración y despliegue en vivo de este sitio web utilizando HTML y buenas prácticas de diseño responsivo.
